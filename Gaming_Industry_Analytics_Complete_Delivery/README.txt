🎮 Gaming Industry Analytics

A data analytics project using Power BI, DAX, and an interactive HTML dashboard to explore gaming sales by genre, platform, year, and region.

Tools
- Power BI
- DAX
- CSV
- HTML, CSS, JavaScript

 Features
- KPI cards and sales charts
- Genre and platform analysis
- Regional sales comparison
- Interactive filters

Note: This project uses synthetic data for learning and portfolio purposes.
